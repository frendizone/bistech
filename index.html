Pertanyaan Umum

Jawaban untuk pertanyaan yang sering ditanyakan

Berapa lama proses pembuatan aplikasi?

Untuk paket Starter sekitar 2-3 minggu. Paket Bisnis 1-2 bulan. Untuk Enterprise tergantung kompleksitas, biasanya 2-4 bulan.

Apakah bisa custom sesuai proses bisnis saya?

Tentu! Itu keunggulan aplikasi custom. Kami akan pelajari alur bisnis Anda dulu, lalu bangun aplikasi yang sesuai — bukan sebaliknya.

Bagaimana sistem pembayarannya?

DP 50% di awal, 30% saat progress, 20% saat selesai. Untuk paket Enterprise bisa dinegosiasikan sesuai milestone.

Apakah ada biaya bulanan?

Untuk hosting & maintenance opsional mulai Rp 300rb/bulan. Tidak wajib — klien bisa self-host jika mau.

Apakah source code jadi milik saya?

Ya, untuk paket Bisnis & Enterprise source code sepenuhnya milik klien. Untuk Starter, source code bisa dibeli terpisah.

Bagaimana kalau ada bug setelah selesai?

Selama masa support (3 bulan - 1 tahun tergantung paket), perbaikan bug gratis. Setelah itu bisa perpanjang kontrak maintenance.
